# Financial Goal Setting and Health Indicators

Holistic financial planning connects short-term cash flow habits with long-term milestones.

### S.M.A.R.T. Financial Goals
- **Specific**: Clearly defined purpose (e.g., "Down payment for home" vs "Save money").
- **Measurable**: Explicit target dollar amount.
- **Achievable**: Grounded in actual net cash flow surplus.
- **Relevant**: Aligned with life priorities.
- **Time-bound**: Explicit target milestone date.

### Required Contribution Formula
$$\text{Required Monthly Savings} = \frac{\text{Target Amount} - \text{Current Balance}}{\text{Months Until Target Date}}$$

### Financial Health Assessment Dimensions
1. **Savings Ratio**: Percentage of gross/net income successfully retained each month ($\ge 20\%$ ideal).
2. **Liquidity Buffer**: Number of months of essential expenses covered in cash.
3. **Net Worth Growth**: Consistent upward trajectory in $\text{Assets} - \text{Liabilities}$.
4. **Budget Discipline**: Consistent variance containment within planned expenditure limits.
